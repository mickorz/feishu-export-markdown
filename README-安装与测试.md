# 飞书文档导出专家 - 增加 Markdown（不包含图片）

## 安装
1. 解压本 ZIP。
2. Chrome 地址栏输入 chrome://extensions，启用「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择此文件夹（包含 manifest.json）。
4. 建议暂时停用商店安装的原版，以免两份插件在飞书页面重复注入。
5. 打开 / 刷新飞书文档，点击页面的悬浮导出按钮。

## 新增功能
- 悬浮菜单新增第五个选项：Markdown（不包含图片）。原有 4 个选项不变。
- 仅选择此模式时，不会请求下载图片，不生成 images 文件夹，也不打包 ZIP；直接下载 .md 文件。
- 此模式会从文档数据中移除图片块，包括嵌套图片块，不保留 Markdown 图片引用。其他文字、表格、代码、标题等保留。
- 点击浏览器工具栏中的插件图标打开的弹窗也加入了相同复选项；多格式选择时以 ZIP 导出，无图 Markdown 名为「文档名.no-images.md」，普通 Markdown 仍为「文档名.md」。
- 原有 Markdown、HTML、Word、全部导出仍按旧逻辑输出（保留图片）。

## 测试建议
1. 包含普通文字、标题、表格、代码块、图片的飞书文档，点击悬浮菜单新选项。确认只下载 1 个 md 文件。
2. 打开 md，确认原文字、表格存在，且不含 `![图片](...)` 引用和图片块。
3. 选择原版 Markdown 或全部导出，确认仍会下载带 images 目录的 ZIP。
4. 通过插件弹窗同时选择 Markdown 和 Markdown（不包含图片），确认 ZIP 内有两份不同文件。
5. 大型/懒加载文档应额外实测，确认文本完整。
